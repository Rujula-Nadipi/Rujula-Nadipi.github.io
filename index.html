    What a data pipeline does, in four steps

    A data pipeline is like a restaurant kitchen: raw ingredients come in, get washed and prepared, get checked, and leave as a finished dish. Press play or pick a step.

    This is exactly what my DMVTek pipeline (below) does, only with far more rows and real map data.

    Featured work · DMVTek (Niyam IT) · 2025

    Turning raw map data into an industry-tagged business dataset

    A Prefect pipeline that pulls Overture Maps places data from AWS S3, cleans it, tags each business with a NAICS industry code, and loads it so dashboards can use it. Select a stage to see what it does and why I built it that way.

    Role Junior Python Developer, 4-person team Stack Python · Prefect · DuckDB/DuckLake · Postgres · Docker/Podman · Superset · pytest
    → → → → 

    
      
    

      
    
        
    Built to be rerun
    Loads use MERGE, so running the flow twice updates rows instead of duplicating them.
    
        
    Config over code
    The NAICS mapping lives in a JSON file, so analysts can extend it without touching Python.
    
        
    Tested
    pytest unit and integration tests with mocks cover the mapping, JSON parsing, upsert logic and the full flow.
    
        
    One-command deploys
    A deploy script sets up the Prefect work pool and ships every flow with just deploy-flows.
    
      
    
      
    The code belongs to my employer, so the repository is private. Snippets above are simplified. I'm happy to walk through the full design in an interview.
